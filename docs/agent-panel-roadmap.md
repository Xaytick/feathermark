# Agent 面板后续待办（优先级）

> 范围：FeatherMark 右侧 Agent 对话面板。本文只列**下一步**该做什么。
> 原则：先保证“对话能稳定用、结果能写回文档”，再谈更强能力。

## P0 — 上线前必须补

1. **会话数据的边界与容量治理**  
   现状：会话存 `localStorage`，图片只存路径，文本附件截断 4000 字。  
   已加基础护栏：最多保留 30 个会话、每个会话最多 50 条消息；超限时提示并自动清理。  
   已支持导出/清空当前会话。待办：按 `workspace` 更精细地清理。

2. **真实 AI 配置下的端到端回归**  
   已用真实 DeepSeek 跑通流式对话、编辑模板、写回 diff；mock 覆盖附件、截断、多代码块等场景。  
   待办：补 401/404/429/超时四种错误态的真实回归。

3. **拖拽路径来源统一**  
   现状：Tauri 全局拖放事件按坐标转发到 Agent 面板；浏览器原生 drop 也能收文件。  
   风险：两条路径可能重复添加。  
   待办：统一走 Tauri 路径事件，根据落点分流到编辑器或 Agent；浏览器 drop 只处理纯文本。

## P1 — 显著改善体验

4. **流式回复（已完成）**  
   Rust 侧 SSE 事件转发，前端逐块渲染；生成时发送按钮变为「停止」，推理模型先显示「思考中」。

5. **附件发送语义增强**  
   当前：文本读摘要、图片只给路径和预览，能否“看懂图片”取决于模型。  
   待办：识别模型能力，支持两种发送模式：① 文本摘要（省 token）；② 图片 data URL（多模态）。让用户切换，并在附件上显示实际发送方式。

6. **上下文选择器**  
   当前：一个按钮切换“当前文档 / 关闭”。  
   待办：可选“仅选区 / 当前文件 / 工作区搜索命中 / 无上下文”，并展示 estimated tokens，避免误把整篇大文档塞进请求。

7. **回复写回文档（已改为补丁 + 文档前后 diff）**  
   当前：要求修改文档时，Agent 输出 REPLACE/DELETE/INSERT 补丁；本地应用补丁生成修改后的文档，
   差异对话框比较「修改前 / 修改后」，用户勾选并点「同意修改」才写回；回答中的代码块带独立复制按钮。  
   下一步：在差异里直接编辑建议内容、支持更细的作用范围。

## P2 — 进阶能力

8. **Skills 从内置常量变成可扩展清单**  
   当前：5 个内置技能，开关存本地。  
   待办：支持用户自定义技能（名称、提示词、快捷键）并按工作区隔离；导入/导出技能配置。

9. **会话搜索与固定**  
   会话列表目前只按时间排序。  
   待办：关键词搜索、置顶会话、按工作区/文档分组，便于“持续交流”不被噪声淹没。

10. **Agent 编辑操作工具化（模板流程已完成，工具调用待做）**  
    已把原 AI 编辑收敛为 Agent 编辑模板：模板可选、参数可配、逐块 diff 后应用。  
    下一步是让聊天中的 Agent 也能**请求**执行某个模板（先展示参数与预览，由用户确认），
    而不是只能由用户从菜单里手动发起。待办：定义工具 schema + 用户确认机制。

## 明确不做（本轮边界）

- 不引入插件市场、MCP 或多代理编排。
- 不做云端会话同步；密钥与会话都只在本地。
- 不做自动多轮重试；失败显式暴露，由用户决定重试。
